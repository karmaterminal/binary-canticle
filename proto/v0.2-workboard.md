## What should become issues vs stay local draft

### Make issues when:
- the question has a named artifact target
- success/failure can be stated clearly
- it is now useful for multiple collaborators / code agents to parallelize

### Keep local draft when:
- the ontology is still changing under the words
- the artifact does not yet know whether it should split
- the question is still really a doc-shape question, not an execution question
